# AI Sales Analyzer

A Python-based sales data analysis project.

## Features

- Reads sales data from CSV
- Calculates total sales
- Finds the best-selling product
- Displays sales summary
- Creates a sales visualization

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib

## Project Purpose

This project was created to practice Python, data analysis, and data visualization skills for an AI/ML career.
